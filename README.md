# Portfólio — Ítalo Leão

Portfólio pessoal em HTML, CSS e JavaScript. Fontes e imagem estão incorporadas no `index.html`; o site não precisa de instalação nem compilação.

## Publicação no GitHub Pages

Repositório previsto: `ItaloSLeao/italosleao.github.io`.

1. Envie os arquivos para a branch `main`.
2. Em **Settings → Pages**, selecione **Deploy from a branch**.
3. Selecione **main** e **/ (root)**, e salve.

Endereço previsto após a publicação: https://italosleao.github.io/

Para atualizar o site, altere o `index.html` e envie um novo commit para `main`.
